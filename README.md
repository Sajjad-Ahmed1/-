# بازار ميسان الثقافي

صفحة عربية متجاوبة، مبنية بـ HTML وCSS وJavaScript، دون اعتماد على حزم خارجية.

## التشغيل

افتح dist/index.html مباشرة في المتصفح. جميع الخطوط والصور والفيديوهات مضمنة محلياً.

للتشغيل عبر خادم محلي من داخل المجلد:

```
python -m http.server 8765 --directory dist
```

ثم افتح http://localhost:8765.

## المحتوى

- الهوية والشعارات والفيديوهات من الملفات التي قدمها صاحب المشروع.
- الصور مقتطفات من الفيديوهات المقدمة، وليست صوراً مولدة أو صوراً لفعالية مختلفة.
- الخط IBM Plex Sans Arabic، بديل مفتوح لخط Graphik المرفق.
- لم يُضف موعد قادم أو عنوان تواصل للمنظمين لعدم توفر بيانات مؤكدة.
- رابط واتساب وإنستغرام تسواهن مستمدان من شعار المكتبة المرفق.
- روابط الخرائط تفتح بحثاً باسم المكان، وليست نقاطاً جغرافية موثقة.
- مصدر سياق الفعالية: https://wattaennews.net/archives/101081

## التحقق

تم فحص الصفحة في المتصفح على سطح المكتب وعلى عرض موبايل 390 بكسل، وتصفية المشاريع وتفاصيل المكتبة وقائمة الموبايل وتشغيل الفيديو. لا توجد صور مفقودة أو زيادة في العرض الأفقي أثناء فحص الموبايل.

## النشر

تعذر الوصول من بيئة التنفيذ إلى خادم Git الخاص بالنشر، لذلك لم تُنشر هذه النسخة على رابط عام. هوية الموقع محفوظة في .openai/hosting.json لاستكمال النشر لاحقاً دون إنشاء موقع آخر.
